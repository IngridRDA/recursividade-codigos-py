# Recursividade em Python

Este repositório contém os códigos desenvolvidos para a atividade prática sobre recursividade, utilizando a linguagem Python.

O objetivo da atividade é aplicar os conceitos estudados sobre funções recursivas, casos base e chamadas recursivas na resolução de diferentes problemas.

## Códigos desenvolvidos

Os códigos estão organizados na pasta `src`:

- `01_fatorial.py` — cálculo do fatorial de um número de forma recursiva.
- `02_fibonacci.py` — cálculo de termos da sequência de Fibonacci de forma recursiva.
- `03_somalista.py` — soma dos elementos de uma lista utilizando recursividade.
- `04_palindromo.py` — verificação de palíndromos utilizando recursividade.
- `05_contaOcorrencia.py` — contagem de ocorrências de um elemento utilizando recursividade.
